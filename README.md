# Horarios de rol para Foundry VTT

Un planificador semanal sencillo para grupos de rol. Cada usuario puede:

- marcar su disponibilidad de lunes a domingo;
- elegir mañana, tarde y/o noche;
- escribir una nota por día, por ejemplo, `solo desde las 18 h`;
- consultar en la misma ventana la disponibilidad de todo el grupo.

Los datos se guardan como una bandera del usuario dentro del mundo de Foundry. El horario se abre desde el botón **Horarios de rol** de la lista de jugadores o desde **Configurar ajustes → Ajustes del módulo**.

## Instalación local

Copia o enlaza la carpeta `horarios-de-rol` dentro de `Data/modules`, reinicia Foundry y activa **Horarios de rol** en la gestión de módulos del mundo.

Compatible con Foundry VTT 12 y 13.
